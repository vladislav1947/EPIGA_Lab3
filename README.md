# Лабораторная работа № 3

## Эволюционный синтез: многокритериальная оптимизация (трек A)

Дисциплина «Эволюционное программирование и генетические алгоритмы».

## Индивидуальный вариант

| Параметр | Значение |
| --- | --- |
| `N` | 15 |
| `Q` | 1 (группа 517) |
| `Y` | 26 |
| **Вариант** `V = 1 + ((17N + 7Q + Y) mod 20)` | **9** |
| Трек | **A. Многокритериальная эволюционная оптимизация** |
| Задача | **Размещение датчиков на графе** |

## Постановка задачи

Дан граф района из `n` вершин (мест установки). Датчик в вершине покрывает
её саму и всех соседей; каждый датчик имеет стоимость. Требуется выбрать
подмножество вершин, достигая трёх конфликтующих целей:

- `f₁(x) = покрытие → максимум` (число покрытых вершин);
- `f₂(x) = стоимость → минимум` (суммарная стоимость датчиков);
- `f₃(x) = устойчивость → максимум` (число вершин, покрытых ≥2 датчиками,
  т.е. сохраняющих покрытие при отказе любого одного датчика).

Критерии противоречивы: каждый датчик растит покрытие, но и стоимость;
устойчивость требует избыточности (перекрытия зон). Ищется не одно решение,
а **фронт Парето** — множество недоминируемых компромиссов.

## Входные данные

Данные синтетические, генерируются детерминированно
(`problem.generate_instance`, `seed = 11`):

- `data/nodes.csv` — таблица вершин: id, координаты, стоимость датчика,
  степень;
- `data/instance.json` — полный экземпляр (координаты, рёбра, стоимости)
  и параметры генерации.

Процедура генерации: координаты — равномерно в квадрате `[0, 100]²`,
ребро при расстоянии < 30 (радиус увеличивается до связности графа),
стоимости — целые из `[5, 50]`. Масштаб: `n = 30` вершин, 78 рёбер.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `problem.py` | Экземпляр задачи (граф, покрытие, стоимость, устойчивость), нормализация, генерация данных |
| `nsga2.py` | NSGA-II: доминирование, быстрая недоминируемая сортировка, расстояние до скопления, турнирная селекция, бинарные операторы, элитарное замещение |
| `metrics.py` | Точный гиперобъём (2D/3D), фильтрация недоминируемых, проверка «поддерживаемости» решений |
| `weighted_sum.py` | Подход взвешенной суммы критериев (ГА на скаляризованной функции) |
| `baseline.py` | Случайный поиск с внешним архивом недоминируемых решений |
| `runner.py` | Серии запусков, статистика, запись CSV |
| `experiments.py` | Все обязательные эксперименты |
| `plots.py` | Проекции фронта Парето, 3D-диаграмма, графики гиперобъёма (matplotlib) |
| `main.py` | Интерфейс командной строки |
| `test_nsga.py` | Самопроверка: сортировка vs перебор, гиперобъём, сходимость |
| `data/` | Входные данные задачи |
| `results/` | Результаты: CSV, графики, характерные решения |

Ядро написано на Python 3.9+, используются `numpy` (численные вычисления)
и `matplotlib` (графики). Готовые реализации NSGA-II не используются.

## Установка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install numpy matplotlib
```

## Запуск

```bash
# 1) Полный набор обязательных экспериментов
python3 experiments.py

# 2) Один запуск NSGA-II: размер фронта, гиперобъём, точки фронта
python3 main.py run --seed 0

# 3) Запуск с другими параметрами
python3 main.py run --seed 42 --pop-size 100 --pm 0.1 --crossover two_point

# 4) Один запуск подхода взвешенной суммы
python3 main.py weighted-sum --w1 0.5 --w2 0.25 --w3 0.25

# 5) Случайный поиск с архивом
python3 main.py random-search --max-fe 20000

# 6) Самопроверка компонентов
python3 test_nsga.py
```

## Параметры алгоритма (базовая конфигурация)

| Параметр | Значение |
| --- | --- |
| Представление особи | бинарная строка длины `n` (`xᵢ = 1` — датчик в вершине `i`) |
| Алгоритм | NSGA-II (собственная реализация) |
| Размер популяции | 100 |
| Бюджет вычислений функции | 20 000 |
| Вероятность кроссинговера | 0.9 |
| Вероятность мутации на бит | 0.05 |
| Кроссовер | равномерный |
| Селекция родителей | турнирная (k = 2) по (ранг, −расстояние до скопления) |
| Замещение | элитарное: объединение родителей и потомков, отбор по рангу и расстоянию до скопления |
| Критерий остановки | лимит вычислений функции (20 000) |
| Число запусков в серии | 21 (seed 0, 1, …, 20) |
| Метрика качества фронта | гиперобъём (точный, 3D), опорная точка (1, 1, 1) |

## Результаты

После запуска `python3 experiments.py` в каталоге `results/` появляются:

- `runs_nsga2.csv`, `history_nsga2.csv` — серия запусков NSGA-II и динамика гиперобъёма;
- `nsga2_fronts.csv` — фронты Парето всех запусков (критерии, число датчиков, списки датчиков);
- `runs_random_search.csv`, `history_random_search.csv` — случайный поиск с архивом;
- `methods_compare.csv` — сводная статистика по гиперобъёму для всех методов;
- `representative_solutions.csv` — три характерных решения из фронта;
- `supported_analysis.csv` — какие точки фронта может найти взвешенная сумма;
- `pareto_projections.png` — три проекции фронта (NSGA-II vs взвешенная сумма vs случайный поиск);
- `pareto_3d.png` — фронт в пространстве критериев;
- `coverage_map.png` — карта покрытия для трёх характерных решений;
- `hv_convergence.png` — динамика гиперобъёма NSGA-II;
- `hv_comparison.png` — сравнение методов по гиперобъёму;
- `flowchart.png` — блок-схема NSGA-II;
- `params.csv` — таблица параметров экспериментов.

Отчёт по работе — `report.md` (исходник) и `report.pdf` (версия для сдачи).
